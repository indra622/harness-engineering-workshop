# v11 참고 A 관점 변경 메모

v11은 v10의 44장을 그대로 두고 15쪽과 16쪽만 바꿨다. 14쪽(OpenCode 순정과 OMH 통합 구성)과 9쪽을 포함한 다른 42장은 v10과 같다.

## 15쪽: 기본기 다음은, 검증과 위임

- **사용자 요청:** 15페이지 제목에 AS-IS, TO-BE를 대놓고 쓰지 않는다. Superpowers는 좋은 절차 모음이고 최신화도 잘 돼 있다. 다만 프론티어 모델은 계획, 구현, 테스트, 반복 수정 같은 실행 기본기를 이미 학습하는 방향이고, 하네스의 다음 초점은 pstack처럼 일에 맞는 검증과 위임, 업무 운영의 상위 층이다.
- **그림 구성:**
  - 위 층(파란색, 굵은 테두리): 업무 운영 층. 성공 기준과 근거, 작업별 절차 선택, 범위 정한 위임, 돌아온 결과 검증. 'pstack에서 참고'.
  - 아래 층(종이색): 실행 기본기. 계획, 구현, 테스트, 반복 수정. 'Superpowers, 잘 만든 기본 절차, 계속 다듬어지는 습관'.
  - 강조는 색과 위치로만 보인다. 전환 화살표는 없다.
  - 아래 띠: '기본기는 모델에, 업무 기준과 위임은 하네스에', 둘째 줄에 '계획하고 시험하는 기본기는 모델에 스며들고, 두 묶음 모두 계획, 위임, 검토, 테스트를 갖춤'.
- **노트:** 전달 의도, 사실과 해석의 구분, 두 층의 출처 설명, 아래 띠 읽는 법을 적었다. 출처 목록에 Superpowers RELEASE-NOTES(고정 커밋)와 방향 해석의 배경 두 글을 더했다.
- **근거:** [비교 자료 v03](../references/pstack-superpowers-comparison-v03.md).

## 16쪽: 맞춤

- 왼쪽 두 상자를 'pstack에서 참고할 운영 방식'과 'Superpowers에서 참고할 기본기'로 바꿨다.
- 점선(Superpowers 비교 참고), OMH 상자의 '같음'과 '포함'은 그대로다.
- 노트의 Superpowers 문단에서 AS-IS, TO-BE 표현을 뺐고, 출처 목록을 15쪽과 맞췄다.

## 검사

- v10의 AS-IS, TO-BE 검사(라벨, 위아래 순서, 전환 화살표)는 v10에만 적용한다.
- v11 검사: 15쪽 제목, 15쪽과 16쪽 화면과 노트에 AS-IS, TO-BE 없음, 15쪽 다각형 화살표 없음, 업무 운영 층이 실행 기본기 위에 있음, 과장된 학습 주장 문구 없음, 15쪽 노트의 사실과 해석 구분과 세 출처 링크, 16쪽 새 라벨과 점선.
