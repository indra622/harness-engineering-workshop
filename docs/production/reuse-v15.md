# v15: 반복성과 복잡성에 따른 하네스의 효용

14쪽 ‘쓰는 이유’ 두 줄만 수정했다. 도식과 배치, 다른 43쪽은 v14와 같다.

- 중심 문구: **반복할수록, 복잡할수록 커지는 하네스의 효용**
- 설명: 분업, 비교, 재검토 절차를 재사용해 복잡한 반복 작업의 준비와 확인 부담을 줄이기

단발성이고 단순한 작업에서는 순정이 더 가벼울 수 있다. 복잡한 반복 작업에서 미리 갖춘 분업과 검증 체계의 가치가 커진다는 메시지이며, 측정된 속도나 비용 개선 또는 복잡도에 비례한 성능 보장이 아니다. 하네스의 준비와 유지, 조율 비용 및 순정에서도 같은 절차를 재사용할 수 있다는 경계는 발표자 노트에 남겼다.

사용자가 합의한 두 줄의 제한된 문구 수정이므로 코디네이터가 직접 적용했다. 주요 덱과 도식은 기존 Claude Remote 구현을 그대로 유지한다. 이전 버전은 보존한다.
