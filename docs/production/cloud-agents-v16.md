# v16 변경 메모: Grokbot 사례 다시 그림, 참고 C 추가

v16은 v15에서 20쪽(원래 18번, 사례 3 Grokbot)을 다시 그리고, 그 바로 뒤에 참고 C(21쪽)를 넣어 45장이 됐다. 본문은 용어 25개와 사례 5개 그대로이고, 참고 화면은 3장이다.

## 사용자 요청

- **20쪽 구성:** 작성자가 실제 구성과 이름을 확인했다: 록식이, 에식이, 소식이, 최저가봇. '원자료 미확인', '첨부 미확인' 표시는 지운다.
- **이 사례를 보는 이유:** 클라우드 서비스를 쓰면 맥미니 같은 상시 장비를 직접 둘 필요가 없다. 하네스를 두는 곳은 우리가 직접 운영하는 클식이에만 있지 않고, 서비스는 여럿이며 Grok Bot은 그중 하나다. 이 메시지를 약한 각주가 아니라 눈에 띄게 둔다.
- **참고 C:** AILC Lv3 강의의 개인 에이전트 셋 비교 한 장을 바로 뒤에 넣는다.

## 바뀐 화면

- **20쪽, '내 맥미니 없이도, 클라우드에서 도는 봇 넷':**
  - 왼쪽: 클라우드 상자 안에 네 봇과 함께 쓰는 것(공유 컴퓨터, 연결한 앱, 루틴)을 두고, 아래에 '사람: 일을 맡기고, 필요하면 승인'을 둔다. 봇의 일과 지휘 관계는 그리지 않았다.
  - 오른쪽: 직접 운영(클식이, 장비와 실행 환경을 우리가 관리)과 클라우드 서비스(Grok Bot, 서비스가 늘 켜진 컴퓨터를 제공)를 견주고, '늘 켜 둔 내 장비 없이도 하네스를 쓸 수 있음'을 크게 적었다.
  - 네 비교 축 목록과 각주는 뺐다.
- **21쪽, 참고 C '맥미니 없이도, 클라우드에서 쓰는 개인 에이전트':**
  - dots(OpenAI), Grok Bot(xAI), Muse(Meta) 세 카드에 들어가는 곳, 맡기는 일, 사람이 보는 곳을 적었다.
  - 아래 띠에 셋의 공통점(클라우드의 자기 컴퓨터, 연결한 앱, 이어지는 기억, 사람의 확인)을 둔다.
  - '본문으로, 22쪽' 링크로 건너뛸 수 있다.
- **43쪽 종합:** Grokbot 줄의 '사용자 설명, 첨부 미확인'을 '클라우드 서비스에서 도는 봇 넷, 작성자가 확인한 구성'으로 바꿨다.

## 노트

- **20쪽:** 화면 읽기, 이 사례를 보는 이유, xAI 공식 설명과 출처, 말하지 않는 것을 적었다. v16 정정이 v10 발췌(S15)보다 먼저 나온다.
  - 정정 내용: 작성자 확인으로 대신한 것, 축 목록을 메시지로 바꾼 것, '늘 켜진 컴퓨터'가 공식 설명을 따른다는 것.
  - 발췌에서는 자료 상태에 관한 옛 두 줄만 뺐다. 가르치는 줄(장면, 정의, 예시, 헷갈리는 지점, 확인 질문, 전환 질문)은 그대로다.
- **21쪽:** 세 서비스의 공식 출처 요약과 링크, 강의 출처, 뺀 조건을 적었다.
- **43쪽:** v16 정정과 함께 S34 발췌의 '첨부 미확인, 독립 검증 없음'을 뺐다.
- **근거와 경계:** [비교 자료](../references/cloud-personal-agents-v01.md).
