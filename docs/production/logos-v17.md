# v17: 세 서비스 로고 추가

- 사용자 요청에 따라 AILC Lv3 원본의 OpenAI, Grok, Meta SVG를 21쪽 참고 C의 세 카드에 추가했다.
- `assets/brand-icons/`에 원본을 보관하고 `copy_v17.py`에서 HTML에 인라인으로 내장한다. 원래 색과 비율을 유지하며 Meta 그라데이션 ID만 문서 안에서 충돌하지 않도록 접두어를 바꾼다.
- 작은 자산 배치 수정이므로 코디네이터가 직접 반영했다. 각 로고는 카드 제목 왼쪽에 48px 기준으로 두고, 제목을 오른쪽으로 옮겨 간격을 확보했다. 주요 내용과 구조의 재설계는 하지 않았다.
- 45장 구성, 20쪽 Grok Bot 사례, 나머지 화면은 그대로다. 과거 산출물을 보존하며 이전 v16의 HTML, manifest와 노트가 바이트 동일하게 재생성되는지 확인했다.
- 전체 Chrome 검사, 21쪽 로고의 실제 벡터 범위와 외부 요청 없음, 화면과 PDF 실물 검수를 통과했다. HTML 하나만으로 로고가 보이며 PDF에도 벡터로 들어간다.
- develop 제작본만 v17로 갱신한다. 공개 main의 v15는 유지한다.
