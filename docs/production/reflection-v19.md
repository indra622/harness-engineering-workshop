# v19 변경 메모: 질의응답 뒤 맺음말

v19는 v18(44장)의 질의응답(44쪽) 뒤에 조용한 맺음말 한 장을 붙여 45장이 됐다. 1쪽부터 44쪽 화면은 쪽 번호의 전체 장수만 빼고 v18과 같다. v17의 참고 C 로고와 v18의 옛 마무리 삭제는 그대로다.

## 사용자 승인

- 질의응답 뒤 마지막 쪽에 짧은 회고를 둔다. 옛 결론 요약이나 목록 마무리를 되살리는 것은 아니다.
- 도식, 카드, 목록, 아이콘, 그림은 넣지 않는다. 여백을 넉넉히 두고 절제된 글자만 쓴다.
- '아련하게'는 흐림이나 사라지는 효과가 아니라, 확신하지 못하는 사람의 솔직한 망설임이다.

## 45쪽 화면

- **제목:** 만들어 보고도, 남아 있는 질문
- **본문:** 일곱 줄, 세 묶음, 승인한 문구 그대로.
  - 공부할수록, 오히려 확신이 줄었어요. / 에이전트가 더 똑똑해지면 해결될 일은 아닐까. / 우리가 더해야 할 구조는 어디까지일까.
  - 누군가는 필요성을 느끼고, / 누군가는 저처럼 질문이 더 생겼을지도 모르겠어요.
  - 그래도 직접 시도하고 알아간 시간은 남겠죠. / 오늘은 답 하나보다, 각자의 질문 하나가 남았으면 해요.
- **디자인:**
  - 밤 테마를 쓴다. 제목 위에 하늘색 짧은 선 하나를 둔다.
  - 제목은 68px, 본문은 34px다.
  - 앞의 두 묶음은 흐린 흰색, 마지막 묶음은 밝은 흰색이다.
  - 이 쪽의 CSS는 v19에만 덧붙여, 이전 판 내보내기는 바뀌지 않는다.

## 노트

작성자가 말하려던 생각을 솔직하게 적었다.

- 만들어 보고 공부할수록 확신이 줄었다.
- 고정된 절차와 다시 쓰는 도구는 반복되는 일에서 쓸모가 있지만, 모든 일에 꼭 필요하지는 않다.
- 듣는 분 중 누군가는 필요를 느끼고 누군가는 질문이 더 생길 수 있다.
- 꼭 무언가를 만들지 않아도, 시도해 본 경험과 질문이 남으면 충분하다.

말하지 않는 것도 적었다.

- 더 똑똑한 모델이 모든 문제를 해결한다는 주장. 화면의 그 문장은 질문이다.
- 새로 측정한 성과.

## 구현

- `copy_v19.py`가 맺음말을 만든다. v18이 지운 원래 번호 41을 다시 써서 새 참고나 용어, 사례 번호를 만들지 않는다.
- 원래 번호 순서는 1~40, 42, 41이다.
- 45장, 용어 25, 사례 5, 참고 3(15A, 16B, 21C), CEO Agent 34쪽, 질의응답 44쪽이다.

## 검사

- **v19 검사:**
  - 마지막 45쪽이 종류 closing, 원래 번호 41임. 질의응답이 44쪽임.
  - 제목과 세 묶음 일곱 줄이 승인 문구와 같음.
  - 도식, 목록, 그림이 없음. 밤 테마임. 옛 마무리 문구가 없음.
  - 1쪽부터 44쪽 화면이 v18과 같음(쪽 번호 제외).
- **기존 검사:** 그대로 유지했다. 원래 번호 순서 검사는 v19에서 41을 끝에 더해 확인한다.
- **대기와 인쇄:** 화면을 바꿀 때마다 글꼴 준비와 220ms를 기다린다. 인쇄 전에는 글꼴 준비, 두 번의 화면 갱신, 250ms를 기다린다. PDF는 45쪽이고 제목은 v19다.
