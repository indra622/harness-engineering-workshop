# v07 참고 화면 두 장 제작 메모

## 무엇을 바꿨나

- OMH 사례(14쪽) 바로 뒤에 선택형 참고 화면 두 장을 넣었다. 이에 따라 전체는 44장이 됐다.
  - 참고 A(15쪽): 같은 개발 요청, 서로 다른 작업 설계
  - 참고 B(16쪽): 가져올 것은 기능 목록보다 작업 방식
- 원래 15쪽부터 42쪽까지는 17쪽부터 44쪽으로 두 장씩 밀렸다. 내용은 v06 그대로다.
  - 쉬는 시간은 28쪽, CEO Agent는 33쪽, 질의응답은 44쪽이다.
  - 용어 25개, 사례 다섯 개, CEO Agent 한 장, 쉬는 시간 한 장은 그대로다. 강의 시간 표기는 어디에도 없다.
- 두 참고 화면은 본문(용어와 사례)에 세지 않는 별도 종류(`reference`)다. 오른쪽 위 '본문으로, 17쪽' 링크로 한 번에 건너뛸 수 있다.

## 왜 넣었나

- OMH 사례를 보고 나면 "다른 팀의 스킬 묶음은 같은 일을 어떻게 다루나, 무엇을 가져오면 되나"라는 질문이 자연스럽게 나온다.
- 참고 A는 같은 기능 추가 요청을 두고 두 공개 스킬 묶음이 먼저 챙기는 것을 나란히 보인다.
- 참고 B는 그 비교를 '내 환경에 맞게 골라 쓰기'로 정리하고 OMH를 적용 예로 든다.
- 근거와 출처 구분은 [pstack과 Superpowers 비교 자료 v01](../references/pstack-superpowers-comparison-v01.md)에 있다.

## 번호를 다루는 방식

- 원래 슬라이드의 v10 출처 번호(S1 등)와 정정 번호는 원래 번호(v06 기준)에 붙어 그대로 따라간다.
- 화면과 노트에서 쪽을 가리키는 숫자만 v07 번호로 옮겼다.
  - 질의응답 화면의 색인
  - 2쪽 노트의 '27번', '35번'
  - 쪽 번호
- 목록 파일과 각 슬라이드의 `data-original` 속성에 원래 번호를 남겼다. 참고 화면에는 `data-reference`(A, B)를 붙였다.
