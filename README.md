# 하네스 엔지니어링

AI에게 일을 맡기는 구조를 설명하는 발표 자료입니다. 현재 공개본은 **v15**입니다.

## 공개 자료

- [HTML 다운로드](https://raw.githubusercontent.com/indra622/harness-engineering-workshop/main/slides/harness-engineering-workshop-v15.html)
- [PDF 다운로드](https://raw.githubusercontent.com/indra622/harness-engineering-workshop/main/slides/harness-engineering-workshop-v15.pdf)

HTML 파일을 내려받아 브라우저로 열면 됩니다. 네트워크 없이 사용할 수 있고, PDF는 44쪽입니다.

오른쪽과 왼쪽 화살표로 이동하고, `N`으로 발표자 노트, `F`로 전체 화면을 엽니다. HTML의 `#s14`처럼 페이지 번호로 바로 이동할 수도 있습니다.

## 제작 자료와 이전 버전

소스, 기획서, 참고 자료, 검사 기록과 과거 버전은 [develop 브랜치](https://github.com/indra622/harness-engineering-workshop/tree/develop)에 보관합니다. 기존 Git 이력은 그대로 유지했습니다.

`main`에는 공개 대상으로 선택한 자료만 둡니다. 일반 수정은 `develop`에서 진행하고, 공개판으로 확정할 때만 이곳에 반영합니다.
